# Mjml.Net vs. MJML (JavaScript)

> Generated by `dotnet run -c Release --project Mjml.Net.Compare`. Do not edit manually.

Both renderers run in-process (no process startup, no disk I/O inside the measured loop) on the templates in `Mjml.Net.Benchmark/Templates`. Beautify and minify are disabled and MJML validation is skipped on both sides, so only the rendering itself is measured. Before measuring, all templates are rendered 20 times so that the .NET JIT and V8 have optimized all code paths.

*First* is the time of the very first (cold) render of each template; for the first template this includes JIT compilation and module loading. *Speedup* is `JS Median / .NET Median`.
